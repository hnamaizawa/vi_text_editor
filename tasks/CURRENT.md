# CURRENT - v0.1.5

## 目的

EmEditor／サクラエディタに近いWindows GUIを維持しつつ、viの移動・検索・行ジャンプ操作をさらに実用的にする。

## v0.1.5 スコープ

- [x] `W` / `B` のWORD移動を維持
- [x] `Ctrl+F` / `Ctrl+B` を1画面移動としてカーソル追従させる
- [x] `Ctrl+D` / `Ctrl+U` を半画面移動として追加
- [x] `/` / `?` の文字列検索を追加
- [x] `n` / `N` で検索を同方向／逆方向へ繰り返す
- [x] `:行番号` で任意行へジャンプ
- [x] `:$` で最終行へジャンプ
- [x] 検索・行ジャンプ・半画面移動のCore単体テストを追加
- [x] 参照モード、Undo下限保護、ファイルI/Oを維持

## 次候補

1. `e` / `E`, `ge` / `gE` のword/WORD末尾移動
2. 数値プレフィックス (`3w`, `5j`, `2Ctrl+F` など)
3. operator + motion (`dw`, `dW`, `cw`, `c$` など)
4. Vim互換に近い検索正規表現と検索ハイライト
5. Visualモード
6. タブ編集
