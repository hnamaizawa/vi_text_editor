# CURRENT - v0.1.26

## 目的

開いたテキストファイルに含まれるURLを、マウスの左シングルクリックでWindowsの既定ブラウザへ安全に渡す。URL以外のクリック、キャレット移動、ドラッグ範囲選択、vi操作は従来どおり維持する。

## v0.1.26 スコープ

- [x] `http://` / `https://` URLの行内検出
- [x] URL上の左シングルクリックでWindows既定ブラウザを起動
- [x] URL上で手の形のマウスポインターを表示
- [x] マウスドラッグをクリックと区別し、範囲選択時はブラウザを起動しない
- [x] URL外のクリックでは従来のキャレット操作を維持
- [x] 日本語がURLより前にある行のUTF-8バイト位置を.NET文字位置へ補正
- [x] 文末の句読点／囲み閉じ括弧をURLから除外
- [x] URL内部の対応する丸括弧／角括弧／波括弧は保持
- [x] URL判定をCoreサービスへ分離し単体テストを追加
- [x] README.md変更履歴・操作説明を更新
- [x] ハーネスをv0.1.26へ更新

## 対象外

- `ftp://`、`file://`、メールアドレスは自動起動しない
- ブラウザ起動そのものはOS既定アプリへ委譲し、Coreテストでは外部プロセスを開始しない

## 次候補

3. mark/jumplist (`m{a-z}`, `'a`, `` `a ``, Ctrl+O/Ctrl+I)
4. wrapped screen-line motion (`gj/gk/g0/g$/g^`)
5. タブの前回セッション復元、ドラッグ並べ替え、ピン留め
