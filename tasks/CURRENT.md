# CURRENT - v0.1.27

## 目的

テキスト内の `http://` / `https://` URLをHTMLリンクのように表示し、入力・貼り付け・削除へ動的に追従させる。既存のシングルクリックによるブラウザ起動は維持する。

## v0.1.27 スコープ

- [x] URLを青色・下線付きで表示
- [x] ファイル読込時に文書内URLを装飾
- [x] 入力・貼り付け・削除時に変更行と隣接行の装飾を更新
- [x] 装飾による文書内容、変更状態、Undo履歴への影響を回避
- [x] 日本語混在行のUTF-8バイト位置を補正
- [x] URL列挙処理をCoreサービスとして単体テスト
- [x] 従来のシングルクリック起動と手形ポインターを維持
- [x] README.md変更履歴・操作説明を更新
- [x] ハーネスをv0.1.27へ更新

## 対象外

- Markdown記法そのものを文書へ挿入、またはHTMLへ変換しない
- `ftp://`、`file://`、メールアドレスはリンク表示しない
- リンク装飾は表示専用とし、保存ファイルの内容には含めない

## 次候補

1. operator + motion の完全化（`d%`, `dfx`, `c}`, `y2w`, `3dd` 等）
2. Visualモードとtext object (`iw`, `aw`, `i(`, `a{` 等)
3. mark/jumplist (`m{a-z}`, `'a`, `` `a ``, Ctrl+O/Ctrl+I)
4. wrapped screen-line motion (`gj/gk/g0/g$/g^`)
5. タブの前回セッション復元、ドラッグ並べ替え、ピン留め
6. Markdownライブプレビュー
7. JSONツリー表示 / JSONPath検索
8. UI自動テスト
