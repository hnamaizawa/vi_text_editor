# CURRENT - v0.1.35

## 目的

`~` の変換対象外文字でもvi方式で右へ1文字進むようにする。

## v0.1.35 スコープ

- [x] 漢字・数字・記号・空白では無変換のまま右へ1文字移動
- [x] UTF-8日本語文字を1文字単位で移動
- [x] 行末を越えて次行へ移動しない
- [x] 無変換操作で直前の`.`繰り返し内容を上書きしない
- [x] 既存の英字大小文字・かな種変換を維持
- [x] README.md変更履歴・操作説明を更新
- [x] ハーネスとアプリ版をv0.1.35へ更新

## 対象外

- 行末から次行への移動は行わない
- 半角カナ変換は追加しない
- 複数文字の一括変換は追加しない

## 次候補

1. operator + motion の完全化（`d%`, `dfx`, `c}`, `y2w`, `3dd` 等）
2. Visualモードとtext object (`iw`, `aw`, `i(`, `a{` 等)
3. mark/jumplist (`m{a-z}`, `'a`, `` `a ``, Ctrl+O/Ctrl+I)
4. wrapped screen-line motion (`gj/gk/g0/g$/g^`)
5. タブの前回セッション復元、ドラッグ並べ替え、ピン留め
6. Markdownライブプレビュー
7. JSONツリー表示 / JSONPath検索
8. UI自動テスト
