# CURRENT - v0.1.34

## 目的

vi/Vimの1文字置換と大小文字変換を追加し、日本語かな変換へ拡張する。

## v0.1.34 スコープ

- [x] `r` + 次入力文字でカーソル位置の1文字を置換
- [x] UTF-8日本語文字を分断せず置換し、改行を保護
- [x] `~` で英字の大文字／小文字を相互変換
- [x] `~` で全角ひらがな／カタカナを相互変換
- [x] JISのShift+`^`を実入力文字`~`として判定
- [x] 単独`^`のfirst-nonblank motionを維持
- [x] `.`による`r`と`~`の繰り返しを追加
- [x] README.md変更履歴・操作説明を更新
- [x] ハーネスとアプリ版をv0.1.34へ更新

## 対象外

- `r`の回数指定は追加しない
- 半角カナ変換は追加しない
- 濁点・半濁点を分離入力した結合処理は追加しない

## 次候補

1. operator + motion の完全化（`d%`, `dfx`, `c}`, `y2w`, `3dd` 等）
2. Visualモードとtext object (`iw`, `aw`, `i(`, `a{` 等)
3. mark/jumplist (`m{a-z}`, `'a`, `` `a ``, Ctrl+O/Ctrl+I)
4. wrapped screen-line motion (`gj/gk/g0/g$/g^`)
5. タブの前回セッション復元、ドラッグ並べ替え、ピン留め
6. Markdownライブプレビュー
7. JSONツリー表示 / JSONPath検索
8. UI自動テスト
