# Known Issues / 未実装項目

v0.1.0時点では以下を今後の開発対象とします。

- 複数タブ編集
- Visual / Visual Lineモード
- `:` コマンド (`:w`, `:q`, `:wq`, `:e` など)
- `/` 検索、`n` / `N`
- 検索・置換ダイアログ、正規表現検索
- 数値プレフィックス (`3dd`, `5j` など)
- operator + motion (`dw`, `d$`, `ciw` など)
- レジスタ、マーク、マクロの本格対応
- シンタックスハイライト設定
- 大容量ファイルでの性能計測と最適化
- セッション復元、最近使ったファイル
- 文字コードをUIから明示変更する機能

Shift_JISはBOMなしファイルがUTF-8として妥当に解釈できない場合にフォールバック判定します。文字コードの完全な自動判別は原理的に曖昧さがあるため、将来はユーザー指定機能を追加します。
